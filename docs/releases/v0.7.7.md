## 中文

下载 **LAN3DShare-0.7.7-win64.zip**，解压后运行 `LAN3DShare.exe`。这是 Windows x64 免安装包；请保留同目录的 `LAN3DCapture.dll`。私有仓库需要登录有访问权限的 GitHub 账号才能下载。

### 本版更新

- 接收端保守修复安静背景中的孤立一至两个采样尖峰，检测会考虑播放放大量。
- 预看限幅与立体声共享增益包络跨音频包连续运行，避免整包增益突变。
- 实时音量调整（包括静音和 100%）使用 5 ms 渐变；播放中断后清除旧延迟音频并淡入恢复。
- 固定增加约 2.1 ms 音频处理延迟，不改变播放速度、视频同步许可或重连代号。
- 新增 `AUDIO_PROTECTION` 日志，记录尖峰修复、限幅和持续缓冲耗尽，便于后续定位。
- 保留 0.7.6 后台异步来源扫描，以及既有 GPU / NVENC / NVDEC、LeiaSR SBS 和接收端音量功能。
- 新增中英文 README 和 7 种界面预览。预览使用示例数据，不是实际连接或性能截图。

### 更新方法

结束共享并退出接收端客户端，解压覆盖原程序目录，再重新打开。设置保留。**接收端必须更新才能启用音频保护**；仅为此功能，发送端可保持 0.7.6。采集 DLL 未变化，本次更新无需重启游戏。

AudioGain、AudioScheduler、AudioMeter、AudioEndpoint 四项检查通过；实际声卡检查使用静音，远端扬声器的爆音改善仍需实际使用确认。4K 指 SBS 总画面 3840×2160；60 FPS 是目标，并非所有设备和网络上的保证。

## English

Download **LAN3DShare-0.7.7-win64.zip**, extract it, and run `LAN3DShare.exe`. This is a portable Windows x64 package; keep `LAN3DCapture.dll` alongside the executable. Downloads from this private repository require a GitHub account with repository access.

### Changes

- Conservative repair of isolated one/two-sample spikes against a quiet background, taking receiver amplification into account.
- A lookahead limiter with a shared stereo envelope that remains continuous across audio packets.
- Live volume changes, including mute and 100%, ramp over 5 ms. Interrupted playback clears old delayed audio and fades back in.
- A fixed processing delay of approximately 2.1 ms, without changing playback speed, video presentation gating or connection generations.
- New `AUDIO_PROTECTION` diagnostics for repaired spikes, limiting and sustained buffer starvation.
- Retains 0.7.6 asynchronous source discovery and the existing GPU / NVENC / NVDEC, LeiaSR SBS and receiver-local volume features.
- Bilingual README with seven UI previews rendered from sample data, not live-session or performance captures.

### Updating

End sharing, exit the receiver client, extract the package over its application directory, and reopen it. Settings are retained. **Update the receiver to enable audio protection**; a 0.7.6 sender remains compatible. The capture DLL is unchanged, so this update does not require restarting the game.

AudioGain, AudioScheduler, AudioMeter and AudioEndpoint checks passed. Physical audio-endpoint tests used silence; improvement on the remote speakers still requires listening validation. 4K means a total packed SBS size of 3840×2160; 60 FPS is a target, not a guarantee for every system or network.
