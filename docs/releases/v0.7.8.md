## 中文

下载 **LAN3DShare-0.7.8-win64.zip**，解压后运行 `LAN3DShare.exe`。私有仓库需要登录有访问权限的 GitHub 账号才能下载。

### 更新内容

- 接收窗口顶部工具栏和音量表仅在鼠标进入控件区域时显示。
- 鼠标移到视频其他区域或离开窗口后，控件在 **3 秒后自动隐藏**；再次移入立即显示。
- 实时音量/状态刷新和视频区域内的鼠标移动不会重置隐藏计时。
- 拖动音量滑条期间保持显示，释放后恢复自动隐藏；窗口失焦后也会隐藏。
- 真实全屏 LeiaSR 继续隐藏全部交织叠层，保留 0.7.7 音频保护。

### 更新与验证

结束共享、退出**接收端**客户端，解压覆盖原程序目录，再重新打开。保留 `LAN3DCapture.dll`；设置不变。发送端无需为此界面修复升级，游戏采集 DLL 未变化，无需重启游戏。

11 项离线界面交互检查和原生 WebView `ViewerUiSmoke` 通过；远端电脑实际使用效果仍需确认。未修改音频、采集、编解码或网络逻辑。

## English

Download **LAN3DShare-0.7.8-win64.zip**, extract it, and run `LAN3DShare.exe`. Downloads from this private repository require a GitHub account with repository access.

### Changes

- The receiver's top toolbar and audio meters appear when the pointer enters their control area.
- They automatically hide **3 seconds** after the pointer moves onto the rest of the video or leaves the window, and reappear on hover.
- Audio/status updates and pointer movement elsewhere in the video do not restart the hide timer.
- Volume-slider dragging keeps controls visible; automatic hiding resumes after release. Losing window focus also schedules hiding.
- Fullscreen LeiaSR continues to hide all weaving overlays. Audio protection from 0.7.7 is retained.

### Update and validation

End sharing, exit the **receiver** client, extract the package over its application directory, and reopen it. Keep `LAN3DCapture.dll` alongside the executable. Settings are preserved. The sender does not need this UI update; the capture DLL is unchanged, so no game restart is required.

Eleven offline UI interaction checks and the native WebView `ViewerUiSmoke` test passed. Behavior on the remote computer still requires use-time confirmation. Audio, capture, codec and network logic are unchanged.
